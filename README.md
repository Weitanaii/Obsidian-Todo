# Obsidian Todo

一个面向 Obsidian 的本地任务管理插件，提供接近 Microsoft To Do 的任务、列表、我的一天、计划和复盘体验。

插件以 Vault 本地数据为核心，不依赖云端服务，支持桌面端和移动端。

## 功能概览

### 任务管理

- 创建、编辑、完成、删除和恢复任务
- 重要程度、开始时间、截止时间、提醒和重复任务
- 备注、标签、优先级、子任务和关联文件
- 任务可移动到不同列表、计划周期或“我的一天”
- 支持软删除回收站，避免误删后无法恢复

### 我的视图

- **我的一天**：按日期管理当天任务，支持全天、早上、中午、下午和晚上分组
- **所有任务**：查看未归入自定义列表的任务
- **我的日程**：日、周、月视图，支持时间轴、拖拽调整时间和点击空白创建任务
- **四象限**：按重要/紧急程度聚合任务
- **复盘统计**：查看日、周、月、年维度的完成情况、趋势和分类分布

### 计划管理

- 人生计划、年度计划、季度计划、月度计划和周计划
- 计划目标支持父子关系和周期拆分
- 年度/月度计划支持卡片视图和列表视图
- 计划卡片显示完成、进行中、搁置、放弃和逾期状态
- 搁置或放弃的目标可以恢复为进行中
- 顶部操作区和统计卡片固定显示，下方内容独立滚动

### 状态管理

任务和目标支持以下状态：

- `active`：进行中
- `shelved`：搁置
- `abandoned`：放弃
- `isCompleted`：完成状态，与上述生命周期状态分开保存

桌面端可以使用右键菜单，移动端可以使用长按底部操作菜单。列表支持按状态筛选，统计视图也会分别显示进行中、搁置、放弃和逾期数量。

### 移动端侧栏

移动端使用 Obsidian 工作区右侧侧栏承载：

- 普通任务详情
- 年度、季度、月度和周目标详情
- AI 推荐候选
- 日程摘要

在“我的日程”中：

- 日视图侧栏显示当前日期待办
- 周视图侧栏显示当前 ISO 周目标
- 月视图侧栏显示当前月份目标

点击摘要项目会关闭详情栏，并跳转到主任务区域定位和高亮对应任务或目标。

## AI 推荐

当前 AI 推荐功能采用**本地规则 provider**，不联网，也不需要 API Key。

目前支持：

- 为“我的一天”生成日待办候选
- 将月度目标拆分为周目标候选
- 根据重要程度、截止日期、父任务、标签和列表进行排序
- 按计划强度计算每日/每周可用容量
- 对长任务进行拆分，避免把超长任务放进单个时间段
- 对重复或高度相似任务进行拦截
- 先在 AI 侧栏中预览，用户点击 `+` 后才保存

当前 provider 是可解释的本地规则实现，不等同于远程大语言模型。未来可以在不改动 UI 和保存流程的情况下替换为远程或本地模型 provider。

## 安装

### 手动安装

1. 下载或构建以下文件：
   - `main.js`
   - `manifest.json`
   - `styles.css`
2. 在 Vault 中创建目录：

   `.obsidian/plugins/obsidian-todo/`

3. 将上述文件复制到该目录。
4. 在 Obsidian 的“第三方插件”设置中启用 **Obsidian Todo**。

### 从源码构建

```bash
npm install
npm run build
```

构建完成后，生成的 `main.js`、`styles.css` 和 `manifest.json` 位于项目根目录。

## 开发

开发模式：

```bash
npm run dev
```

生产构建：

```bash
npm run build
```

项目主要目录：

```text
src/
├── models/       # 任务、列表、标签等数据模型
├── services/     # 存储、任务、统计、AI 推荐服务
├── views/        # 主视图、导航栏、详情栏、AI 侧栏
├── ui/           # 弹窗和选择器
└── utils/        # 日期、周期、重复任务和排序工具
```

## 数据存储

任务数据存储在当前 Vault 的 `todo/` 目录中：

- `database.json`：任务和目标数据
- `lists.json`：自定义列表配置
- `tags.json`：标签配置
- `groups.json`：列表分组配置
- `backups/`：自动备份文件

数据默认保存在本地，不会自动上传到第三方服务。

## 兼容性

- Obsidian `1.0.0` 或更高版本
- 支持桌面端
- 支持移动端
- 中文和英文界面
- 兼容深色和浅色主题，主要使用 Obsidian CSS 变量

## 当前限制

- AI 推荐目前是本地规则推荐，不是远程大模型生成
- 远程 AI provider、API Key 配置和网络隐私设置尚未开放
- 移动端部分复杂交互仍需要在真实设备上持续回归验证
- 暂未提供自动化端到端测试套件

## 项目状态

当前版本：`0.1.0`

核心任务管理、计划视图、日程视图、复盘统计、回收站、重复任务、移动端侧栏和本地 AI 推荐已经实现，项目仍处于持续完善阶段。
